# Tech Wiki

Solo tech wiki starting point using plain Markdown.

## Structure
- docs/: actual content
- templates/: document templates
- assets/: images or diagrams

## Conventions
- One topic per file
- Use lowercase-kebab filenames (e.g., deploy-api.md)
- Keep summaries at the top of each doc

## Quick start
- Add new docs under `docs/` using templates in `templates/`.
- Update `docs/index.md` with new links.
